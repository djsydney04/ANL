# Independently recomputed measurements

Every series has six retained samples after two warmups. Times below are milliseconds; seven decimal places preserve integer or half-integer nanosecond medians exactly. Ranges are minimum–maximum. RSS is bytes reported by Darwin wait4 for the reaped immediate child, not summed simultaneous process-tree memory. Native bytes are full executable file sizes. CPU time includes the host wait4 accounting of reaped descendants; build CPU can exceed wall time.
