# APL

APL is a programming language under development for native systems software and
capability-controlled agent applications, with strong static types and integrated
formal verification.

The project is in **Phase 0, architecture research**. There is no compiler,
installable release, or established safety theorem yet. Proposed designs are not
implemented guarantees.

This checkout and its GitHub repository are named **ANL**, as selected by the
founder. The founding charter names the language **APL**. Repository renaming and
public package-name availability have not been decided. This project is unrelated
to the existing APL array-programming language.
